 20. FAIBLESSES CONNUES D'ACROBAT (opportunités pour Acrux)
--------------------------------------------------------------------------------
- Lourdeur : temps de démarrage long, consommation mémoire élevée, installateur volumineux (>1 Go)
- Interface encombrée et changée fréquemment, multiples couches (ancienne / nouvelle expérience)
- Prix : abonnement mensuel élevé, IA facturée en supplément, fonctionnalités clés réservées à Pro
- Télémétrie et services cloud imposés, connexion Adobe requise pour de nombreuses fonctions
- Fonctions IA nécessitant un envoi des documents dans le cloud (pas d'IA locale / hors-ligne)
- Pas de Linux
- Édition de texte imparfaite sur mises en page complexes (reflow limité, polices approximatives)
- OCR de qualité moyenne sur documents manuscrits / dégradés, plus lent que les moteurs modernes
- Formulaires XFA en fin de vie sans remplacement moderne
- Comparaison de documents limitée (pas de diff sémantique fin)
- Pas de collaboration hors-ligne, pas de fusion de conflits
- Scripting JavaScript vieillissant (ES3/ES5), pas de Python / API moderne côté desktop
- Absence de gestion de versions intégrée type Git, de workflow de validation avancé natif
- Accessibilité : balisage automatique encore imparfait, correction manuelle laborieuse
- Modèle de plug-ins fermé (SDK C++ sous licence)
